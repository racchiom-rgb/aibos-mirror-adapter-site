Last updated: October 27, 2026

This policy describes the currently confirmed data-handling behavior of AIBOS Mirror Adapter, a privately operated integration used by its owner. This page is about this adapter and its identified related document operations, not every component of the wider AIBOS environment.

Information accessed

The application requests Google's https://www.googleapis.com/auth/drive scope, which can grant broad access to files in the authorized Google Drive account. Its known workflows access designated local documents and corresponding Google Drive files, including content and metadata needed for copying and verification. The same authorization configuration also supports limited additions to Google Docs in related workflows.

How information is used

  • Copy designated local documents to the owner's Google Drive mirror.
  • Read mirrored documents to check consistency with the designated local source.
  • Perform limited additions to Google Docs in related, specifically configured operations.
  • Maintain records and backups needed to operate, check, and investigate these workflows.

The declared Drive permission is broader than the subset of documents that the known workflows are configured to process.

Where information is kept

The identified workflow uses the owner's local computer and owner-managed Google Drive. Operational evidence and backups may also be retained locally. OAuth access and refresh tokens used to authorize Google API requests are stored in the local configuration used by the integration. Token-related recovery processes may create protected local backup copies. These credentials are used to authenticate the integration with Google services; this page does not claim that local token files are encrypted. Google processes information stored in Google Drive and Google Docs according to its own service terms and policies.

Sharing and disclosure

For the operations covered by this policy, selected documents and related metadata are transmitted to Google Drive or Google Docs as needed to maintain and verify the owner-managed mirror and carry out the related configured document updates. This policy covers these identified adapter operations only. It does not describe or make representations about other AIBOS components or integrations that have not been assessed.

Website hosting and visitor information

This public information website is intended to be hosted using GitHub Pages, a service operated by GitHub. When someone visits a GitHub Pages site, GitHub logs the visitor's IP address for security purposes, whether or not the visitor is signed in to GitHub. Website hosting is separate from the AIBOS Mirror Adapter's Google Drive and Google Docs document operations. For more information about GitHub's handling of website visitor information, see the GitHub Pages documentation and GitHub Privacy Statement.

Retention and deletion

Some temporary verification files are deleted after use. A single automatic deletion period for all mirrored documents, operational evidence, and backups has not been established. Retained items must be reviewed and deleted using the appropriate local or Google Drive controls according to the owner's operational requirements. Revoking Google account access does not itself remove existing copies or backups.

Access and security

The integration is intended for owner-only operation, with access to Google data granted through Google's authorization flow. The current evidence does not support a blanket claim about encryption configurations, universal retention deadlines, or security controls across every AIBOS component.

Changes

This policy may be updated when the adapter's verified operation or data-handling practices change. The updated date at the top of the page will be revised accordingly.

Questions or deletion requests

To ask about this adapter or request assistance with data deletion, contact the application owner using the published support contact: aibos.hq.jp@gmail.com.
